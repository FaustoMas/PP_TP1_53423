# PP_TP1_53423
## Descripción del Proyecto
El proyecto está estructurado de manera incremental según los ejercicios solicitados:
* **Ejercicio 1 (`E1`):** Modelado básico de la clase `EventoUniversitario` con niveles de encapsulamiento, atributos de instancia, variables de clase estáticas y constructores (incluyendo constructor de copia).
* **Ejercicio 2 (`E2`):** Escalado del modelo integrando relaciones estructurales. Se implementó la agregación de `Sala`, la composición de `Actividad` y la clase asociativa `Inscripcion` para registrar a los estudiantes.
* **Ejercicio 3 (`E3`):** Implementación de herencia y polimorfismo. Se transformó `Actividad` en una clase abstracta y se crearon las subclases concretas `Charla` y `Taller`, aplicando métodos finales y cálculos polimórficos de costos.
* **Ejercicio 4:** Elaboración del mapa de memoria (Stack y Heap) que representa gráficamente las referencias y el ciclo de vida de los objetos en tiempo de ejecución.
